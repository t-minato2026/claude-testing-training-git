## テストケース詳細

### B1-TC-01　往復・正常照会（TOP画面から）

| 項目 | 内容 |
| :--- | :--- |
| テストケースID | B1-TC-01 |
| 対象画面/イベント | B101、B102、イベント B10101 |
| 区分 | 正常系 |
| テスト目的 | TOP 画面から往復で空席照会を実行し、空席照会画面に遷移して往路・復路の空席状況一覧が表示されることを確認する |
| 前提条件 | TOP 画面が表示されている |
| テスト手順 | 1. フライト種別：「往復」を選択<br>2. 出発空港：「東京(羽田)」、到着空港：「大阪(伊丹)」を選択<br>3. 往路搭乗日：翌日の日付を入力<br>4. 復路搭乗日：翌々日の日付を入力<br>5. 搭乗クラス：「一般席」を選択<br>6. 「照会ボタン」を押す |
| 期待結果 | ・空席照会画面（B102）に遷移する<br>・往路便の選択情報（搭乗日・便名・空席状況一覧）が表示される<br>・復路便の選択情報が表示される |
| 関連遷移 | #1 → #2 → #7 |
| 関連メッセージ | - |
