# 空席照会プロセス 状態遷移図

対象画面：TOP画面（A001）、空席照会条件入力部品（B101）、空席照会画面（B102）  
対象イベント：B10101（照会ボタン・TOP画面）、B10102（照会ボタン・空席照会画面）、B10202（前日照会）、B10203（翌日照会）  
参照：ATRS 外部設計書 Markdown版 第1.7.0版

---

## 状態遷移図

```mermaid
stateDiagram-v2
    direction TB

    [*] --> TOP画面_初期表示 : アクセス（未ログイン/ログイン済み）

    state TOP画面 {
        TOP画面_初期表示 --> TOP画面_入力中 : 照会条件入力

        TOP画面_入力中 --> TOP画面_クライアントエラー : 照会ボタン押下（B10101）\n[クライアント検証NG]\n・出発日 未入力・不正\n・フライト種別 未選択\n・搭乗クラス 未選択

        TOP画面_クライアントエラー --> TOP画面_入力中 : 入力修正

        TOP画面_入力中 --> TOP画面_サーバエラー : 照会ボタン押下（B10101）\n[クライアント検証OK→サーバ検証NG]\n・同一区間指定 → e.ar.b1.5001\n・復路日＜往路日 → e.ar.b1.5002

        TOP画面_サーバエラー --> TOP画面_入力中 : 入力修正
    }

    state 空席照会画面 {
        空席照会画面_結果表示 --> 空席照会画面_クライアントエラー : 照会ボタン押下（B10102）\n[クライアント検証NG]

        空席照会画面_クライアントエラー --> 空席照会画面_結果表示 : 入力修正

        空席照会画面_結果表示 --> 空席照会画面_サーバエラー : 照会ボタン押下（B10102）\n[サーバ検証NG]\n・e.ar.b1.5001 / 5002\n・e.ar.b1.2001 (照会対象外日)\n・e.ar.b1.2002 (運行なし区間)\n・e.ar.b1.2003 (フライトなし)

        空席照会画面_サーバエラー --> 空席照会画面_結果表示 : 入力修正

        空席照会画面_結果表示 --> 空席照会画面_結果表示 : 前日照会ボタン（B10202）\n翌日照会ボタン（B10203）

        空席照会画面_結果表示 --> 空席照会画面_結果表示 : 照会ボタン押下（B10102）\n[全検証OK・新条件で再照会]
    }

    TOP画面_入力中 --> 空席照会画面_結果表示 : 照会ボタン押下（B10101）\n[全検証OK]\nフライト一覧表示

    空席照会画面_結果表示 --> [*] : 予約ボタン押下（B20103）→ 予約プロセスへ
```

## 状態一覧

| 状態 | 説明 |
| :--- | :--- |
| TOP画面_初期表示 | フォーム初期値あり（往復・東京(羽田)・当日・一般席）のボタン押下待ち状態 |
| TOP画面_入力中 | 照会条件を入力済み、またはエラー修正後のボタン押下待ち状態 |
| TOP画面_クライアントエラー | Parsley による入力チェック NG。エラーメッセージをフォーム脇に表示 |
| TOP画面_サーバエラー | サーバ側ビジネスルール NG。エラーメッセージを画面上部に表示 |
| 空席照会画面_結果表示 | 照会結果（空席一覧）を表示中。画面上部に再検索フォームあり |
| 空席照会画面_クライアントエラー | 再検索時クライアントエラー表示状態 |
| 空席照会画面_サーバエラー | 再検索時サーバエラー表示状態 |
