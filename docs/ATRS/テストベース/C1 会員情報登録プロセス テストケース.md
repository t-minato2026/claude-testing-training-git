## テストケース詳細

### C1-TC-01　正常登録フロー（C101→C102→C103）

| 項目 | 内容 |
| :--- | :--- |
| テストケースID | C1-TC-01 |
| 対象画面/イベント | C101→C102→C103、イベント C10101, C10201 |
| 区分 | 正常系 |
| テスト目的 | 全必須項目を正しく入力して会員登録確認→完了まで遷移し、会員番号が発行されることを確認する |
| 前提条件 | 未ログイン状態でヘッダの「会員登録ボタン」が表示されている |
| テスト手順 | 1. ヘッダの「会員登録ボタン」をクリックする<br>2. 会員情報登録画面（C101）に全必須項目を有効な値で入力する<br>3. 「登録確認ボタン」を押す<br>4. 会員登録確認画面（C102）の内容を確認する<br>5. 「登録ボタン」を押す |
| 期待結果 | ・会員登録確認画面（C102）に入力内容が表示される<br>・会員登録完了画面（C103）に遷移する<br>・会員番号が表示される（システム自動採番） |
| 関連遷移 | #1 → #2 → #7 → #8 |
| 関連メッセージ | - |
