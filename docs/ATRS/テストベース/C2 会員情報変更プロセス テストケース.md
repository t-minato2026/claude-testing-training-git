### C2-TC-02　C201 正常更新（パスワード変更なし）

| 項目 | 内容 |
| :--- | :--- |
| テストケースID | C2-TC-02 |
| 対象画面/イベント | C201、イベント C20101 |
| 区分 | 正常系 |
| テスト目的 | パスワードを変更せずに会員情報を更新した場合に成功メッセージ i.ar.c2.2001 が表示されることを確認する |
| 前提条件 | ログイン済みで会員情報変更画面（C201）が表示されている |
| テスト手順 | 1. 住所フィールドを変更する（例：「東京都港区1-1-1」→「東京都品川区2-2-2」）<br>2. 現在のパスワード・変更パスワード欄は空欄のまま<br>3. 「更新ボタン」を押す |
| 期待結果 | ・会員情報変更画面（C201）に留まる（更新後の値を再表示）<br>・成功メッセージ「会員情報を更新しました。」が表示される<br>・変更した住所が更新後の値で表示される |
| 関連遷移 | #2 → #7 |
| 関連メッセージ | i.ar.c2.2001 |

### C2-TC-07　C201 更新完了後に継続して変更

| 項目 | 内容 |
| :--- | :--- |
| テストケースID | C2-TC-07 |
| 対象画面/イベント | C201、イベント C20101 |
| 区分 | 正常系 |
| テスト目的 | 会員情報更新完了後、そのまま別の項目を変更してもう一度更新できることを確認する（継続変更フロー） |
| 前提条件 | ログイン済みで会員情報変更画面（C201）の更新成功メッセージが表示されている状態 |
| テスト手順 | 1. C2-TC-02 の手順で更新を完了し、成功メッセージ「会員情報を更新しました。」を確認する<br>2. 成功メッセージが表示されたまま、さらに別のフィールド（例：電話番号下4桁）を変更する<br>3. 「更新ボタン」を押す |
| 期待結果 | ・画面遷移せずに再度更新が実行される<br>・成功メッセージ「会員情報を更新しました。」が表示される<br>・変更した電話番号が更新後の値で表示される |
