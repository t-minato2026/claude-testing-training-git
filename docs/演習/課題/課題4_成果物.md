## 補足：設計上のポイント

| 観点 | 内容 |
|---|---|
| ビジネスルール境界（#17〜18） | 年齢18は「ちょうど有効」、17は「ちょうど無効」として2点を必ずテスト |
| 電話番号3の固定長（#47〜48） | 「固定長」仕様は上下どちらのズレも無効なので、上下両側の境界値を確認 |
| 搭乗者年齢の0歳（#74） | 代表者と異なり18歳制限が適用されないため、実装で誤って制限が混入していないか確認するために含める |
| メールアドレスの256文字（#53〜54） | マルチバイト文字と混在する可能性があるため、実際には文字数カウント方式（byte/char）も確認推奨 |
| 搭乗者0件（#60） | 必須コレクションの空配列送信はAPIが見落としやすい境界のため優先度高 |
