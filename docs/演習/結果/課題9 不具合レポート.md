## BUG-001　子供搭乗者（12歳未満）に子供料金が適用されず大人料金で合計金額が算出される

| 項目 | 内容 |
|------|------|
| 不具合ID | BUG-001 |
| タイトル | 子供搭乗者（12歳未満）に子供料金が適用されず大人料金で合計金額が算出される |
| 重大度 | **A**　― 金銭への直接的影響（子供搭乗者が大人運賃で課金されるため過大請求が発生する） |
| 発見テストケース | TC-R-001 |
| 検出バージョン | v1.8.1-FaRSeT-bug |
| 使用環境 | ブラウザ: Chromium（Playwright）/ アプリ: http://localhost:8083/atrs/ |
| 報告日 | 2026-05-14 |

---

## 再現条件

- ログイン済み会員が片道フライトを予約する
- 搭乗者に12歳未満（年齢 0〜11）の子供を1名以上含む

---

## 再現手順

1. `http://localhost:8083/atrs/ticket/search?topForm` へアクセスする
2. 以下の条件で空席照会を実行する
   - フライト種別：片道
   - 区間：東京(羽田) → 大阪(伊丹)
   - 往路搭乗日：本日から7日後
   - 搭乗クラス：一般席
3. 表示されたフライト一覧から最初のフライトを選択し、「予約」ボタンを押す
4. ログインダイアログ（B201）で以下を入力してログインして予約する
   - 会員番号：`0000000001`
   - パスワード：`aaaaa11111`
5. お客様情報入力画面（B202）で「搭乗者を追加」ボタンを押す
6. 追加された搭乗者2の情報を以下のとおり入力する
   - 姓：テスト　／　名：タロウ
   - 年齢：**5**
   - 性別：男性
7. 「予約確認」ボタンを押して申し込み内容確認画面（B203）へ遷移する
8. B203 に表示される「合計金額」を確認する

---

## 発生事象（Actual）

合計金額が **¥41,200** と表示された。

これは大人運賃 ¥20,600 の **2名分**（¥20,600 × 2）に等しく、
5歳の搭乗者にも大人と同額の運賃が適用されている。

```
expect(received).toBeLessThan(expected)

Expected: < 41200
Received:   41200
```

---

## 期待結果（Expected）

仕様上、子供料金は以下の式で算出される。

```
子供運賃 = 基本運賃 × 60% − 運賃種別ごとの割引額
```

子供運賃は大人運賃より低くなるため、合計金額（大人1名＋子供1名）は
**大人2名分の運賃（¥41,200）を下回る**こと。

```
合計金額 < ¥41,200
```

---

## 影響範囲

- 12歳未満の搭乗者を含む**すべての予約**において、子供割引が適用されず過大な金額が請求される
- 片道・往復いずれの予約フローでも同様に発生する可能性がある

---

## 補足

正常バージョン（http://localhost:8082/atrs/）では同一手順を実行すると合計金額が ¥41,200 を下回り、子供料金が正しく適用されることを確認済み。
